# Agent Coordination

This directory is the shared coordination ledger for ChatGPT, Claude, and Manus.

- `WORK_QUEUE.md`: task ownership and current status.
- `DECISIONS.md`: approved decisions and rationale.
- `HANDOFFS.md`: concise agent-to-agent handoff log.

Update these files when task ownership or project decisions change. Do not use chat history as the only record of a decision.
